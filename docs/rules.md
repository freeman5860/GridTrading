# 网格交易规则（引擎实现版）

本文件描述 `src/core/engine.ts` 实际执行的规则，规则引擎的测试（`test/engine.test.ts`）以本文件为准。
规则整合自两份网络公开分享：一份"涨跌分档操作法"（第一层），一份狐利《什么是网格交易？》（第二层与适用条件）。

## 基本概念

- **基准价 P0**：每个标的在配置里的 `basePrice`。涨跌幅 = (现价 − P0) / P0。
- **一轮**：从设定 P0 开始，到 +100% 清仓或用户修改 P0 为止。修改 P0 即开始新一轮，已触发档位清零。
- **两层**：第一层"分档仓位管理"决定大方向加减仓；第二层"区间小网格"在震荡区间内低买高卖。**同一次检查两层都触发时，第一层优先**，网格本次不操作，并把网格锚点移到现价附近，避免之后补发过期的网格信号。

## 适用条件

不满足以下条件不建议做网格（目前作为使用说明，后续接入 AI 后会在分析中提示）：

1. 只做场内品种（股票、场内 ETF/LOF、港美股）。场外基金不能做。
2. 标的要有波动但不会归零；新手优先宽基指数 ETF。
3. 市场处于震荡状态。单边上涨或单边下跌行情中网格失效。
4. 有备用资金：至少覆盖第一层的两次加仓和网格下半区的全部买单。
5. 每格利润应不低于往返手续费的 3 倍（配置 `fee` 后引擎会自动检查并提示）。

## 第一层：分档仓位管理

| 涨跌幅 | 操作 |
|---|---|
| −15% 以内 | 不操作 |
| 跌到 −15% | 增持当前持仓的 10% |
| 跌到 −25% | 再增持当前持仓的 25% |
| 跌破 −25% | 不再机械加仓，提示复核基本面 |
| +25% 以内 | 继续持有 |
| 涨到 +25% / +35% / +45% / +60% | 依次卖出当时剩余持仓的 10% / 20% / 30% / 40% |
| 涨到 +100% | 清仓，本轮结束 |

执行细则：

- **每档每轮只触发一次**。价格在档位附近来回波动不会重复提醒；跌到 −15% 后反弹再跌回 −15%，本轮也不再触发。
- **跳空越过多档时依次执行**所越过的每一档，后一档按前一档执行后的持仓计算。
- 计算基于配置中的 `position`（总持仓，含网格仓）。成交后请更新 `position`。
- 买入受 `cash`（可用资金）限制，不足时按资金下调并提示。

## 第二层：区间小网格

- 在 `[lower, upper]` 内按 `step` 生成价位：固定金额为等差，百分比（如 `"2%"`）为等比。
- 首次启用时，锚点设在离现价最近的价位，网格仓为 `initialLots` 格（默认 0）。
- 价格每**下穿**锚点下方一格，买入 `size`，网格仓 +1；一次跌穿多格时逐格买入。
- 价格每**上穿**锚点上方一格：有网格仓时卖出 `size`、网格仓 −1；**没有网格仓时不卖**（每笔卖出必须对应一笔更低价位的买入）。
- 跌破下限：停止网格买入，交给第一层；突破上限：网格停止，底仓交给第一层。两种情况都提示重新评估区间。
- 网格参数（区间、间距、每格数量）变化时，网格重新初始化。

## 多市场

| | A 股 | 港股 | 美股 |
|---|---|---|---|
| 代码写法 | `sh510300` / `510300` / `510300.SH` | `hk00700` / `700` / `0700.HK` | `usAAPL` / `AAPL` |
| 交易单位 | 100 股/份 | 每只股票不同，自动从行情读取 | 1 股 |
| 币种 | CNY | HKD | USD |

- 数量按交易单位取整到最近的整手；**恰好半手时向下取**，避免实际买卖量超过规则比例。结果不足一手时不操作并提示。
- 资金和持仓都按标的自身币种计算，不做汇率换算。
- 停牌或无有效价格时不做判断，也不更新状态。
